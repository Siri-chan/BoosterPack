# Siri's Balatro Booster Pack
## Installation
Install Steamodded and Lovely, then glue this and [Talisman](https://github.com/SpectralPack/Talisman) into your `Mods/` folder.

Easiest way to keep this mod up to date is with `git clone`:
```
git clone https://github.com/Siri-chan/BoosterPack -b stable --single-branch 
```
